### 팩토리얼
i팩토리얼 (i!)은 1부터 i까지 정수의 곱
ex) 5! = 5 * 4 * 3 * 2 * 1 = 120 

정수 n이 주어질 때 다음 조건을 만족하는 가장 큰 정수 i를 구하기


```js
function solution(n) {
	let i = 1;
	let factorial = 1;
	while (factorial <= n) {
		i += 1;
		factorial *= i;
	} 
	// factorial === n일경우도 실행되기때문에 i-1 리턴
	return i -  1; 
}
```
