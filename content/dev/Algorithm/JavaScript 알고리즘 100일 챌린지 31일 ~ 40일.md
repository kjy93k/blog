### 등수 매기기

영어 점수와 수학 점수를 담은 2차원 정수 배열 score가 주어질 때, 영어 점수와 수학 점수의 평균을 기준으로 매긴 등수를 담은 배열 구하기

```js

function solution(score) {
    let 총합 = score.map(v => v[0] + v[1])
    // sort는 원본배열을 수정
    let 정렬된배열 = 총합.slice().sort((a, b) => b - a)
    return 총합.map(v => 정렬된배열.indexOf(v) + 1);
}

```
