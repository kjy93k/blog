#  베놈 스피커처럼 몽글거리는 버블 이펙트 만들기

유튜브에서 보았던 **'베놈 스피커'** 의 몽글거리는 물방울 형태가 인상 깊었습니다.  
물방울이 소리에 반응해서 튀는 게 아니라, **형태가 아예 물처럼 변하는** 시각적 느낌이 흥미로웠죠.

그래서 CSS 애니메이션만으로 유사한 분위기의 이펙트를 구현해보고자 간단한 실험을 진행했습니다.
